# Pizza Boy

Pizza Boy is an open-world arcade racing game developed over three years as a solo project using Unity.

The project started as a small prototype and gradually evolved into a complete game, providing experience in game architecture, optimization, debugging, version control, and shipping a finished product.

## Features

- Open-world environment
- Arcade-style driving physics
- Quests with objectives
- AI traffic
- Save/load system
- Audio effects and music
- Day/Night Cycle
- Keyboard and partial controller support

## Technologies

- Unity
- C#
- Git
- Visual Studio IDE
- JetBrains IDE

## What I Learned

This project taught me a great deal about software development, including:

- Writing maintainable and modular code
- Performance optimization
- Refactoring existing systems
- Version control with Git
- Debugging large codebases
- Managing a long-term software project
- How to use a debugger, breakpoints and unity profiler

## Challenges

Some of the biggest challenges included:

- Maintaining a growing codebase over several years
- Optimizing performance as new systems were added
- Balancing new features with bug fixing
- Staying motivated during the final stages of development

  ## Technical Highlights

- Built as a solo project (got help with art and soundtrack and some help with writing AI Traffic from friends)
- 181 C# files with 43,198 lines of code and 4505 lines of comments
- Developed over 3 years
- Implemented physics based destruction system
- Reduced frame-time from 60ms to 16ms by using object pooling for my destruction system
- Custom save/load system that saves data to an encrytable json
- Implemented a custom day/night cycle system, with dynamic environment sound and visual effects
- Implemented AI traffic
